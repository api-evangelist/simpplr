# Simpplr API documentation Documentation

> Easily integrate to and expand on the premier Intranet provided by Simpplr with full API documentation and tutorials.

## API Reference: Getting Started
- [Welcome to Simpplr’s Extensibility Center](https://developer.simpplr.com/reference/welcome-to-simpplrs-extensibility-center.md)

## API Reference: APIs
- People
  - [Search for People by ID](https://developer.simpplr.com/reference/search-for-people-by-people-id.md): Use this API to search for People by their PeopleId or Salesforce user id.
- Content
  - [Search for Contents](https://developer.simpplr.com/reference/search-for-contents.md): Use this API to search for Contents.
  - [Search for Page Categories](https://developer.simpplr.com/reference/search-page-categories.md): This search API is used to retrieve all page categories based on the specified 'site-id' and 'sort- by' (either 'createdNewest' or 'createdOldest') provided in the request body. Additionally, we have…
  - [Get all Events](https://developer.simpplr.com/reference/get-all-events.md): Use this API to search for Contents.
  - [Update an Event](https://developer.simpplr.com/reference/update-an-event.md): Use this API to update an Event.
- Notifications
  - [Create a Notification](https://developer.simpplr.com/reference/create-a-notification.md): Use this API to create a Notification.
